# OoT Hackroom

## Instalación
1. Instala Node.js LTS.
2. Abre CMD en esta carpeta.
3. Ejecuta:
   npm install
4. Después:
   npm run dev
5. Abre http://localhost:5173/

## Cambiar porcentaje
Edita `src/projectData.js`:

`progress: 27`

Puedes cambiar también `phase`, `status`, `lastUpdate`, descripción, objetivos y créditos.

## Build
`npm run build`

La carpeta publicable es `dist/`.

La etiqueta `noindex` no es una contraseña. Para privacidad real en Internet se recomienda Cloudflare Access.
